# MES 工厂管家 · 系统管理员手册

> 适用对象：系统管理员（admin 角色）· 版本：2026-08 · 配套文档：《使用手册》《模块业务逻辑手册》《岗位职责与操作流程手册》

## 1. 管理员职责总览

系统管理员负责 MES 的**部署、账号权限、基础数据、系统配置、备份恢复与日常运维**。日常业务操作（报工、检验、出入库）由各岗位员工执行，管理员一般不直接操作业务单据，但需要保障系统稳定、数据安全、权限合规。

| 职责域 | 具体内容 | 对应章节 |
|--------|----------|----------|
| 部署运维 | 安装、启动/停止、生产部署、HTTPS | 2-3 |
| 权限管理 | 用户开户、角色分配、权限配置 | 4 |
| 基础数据 | 初始化车间/工序/产品/BOM/工艺路线 | 5 |
| 系统配置 | 系统参数、AI 等扩展配置 | 6 |
| 数据安全 | 备份、恢复、导出 | 7 |
| 审计 | 登录日志、操作日志、状态日志 | 8 |
| 排障 | 常见故障处理 | 9 |
| 安全 | 口令、密钥、权限最小化 | 10 |

## 2. 安装与部署

### 2.1 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+（推荐 3.13） | 后端运行环境 |
| Flask | 2.x / 3.x | Web 框架（已随项目安装） |
| openpyxl | 3.x | Excel 导入导出 |
| SQLite | 3.x | 默认数据库，零依赖 |

### 2.2 首次安装

```bash
# 1. 安装依赖（进入项目根目录）
pip install flask openpyxl waitress

# 2. 初始化数据库（首次启动自动建表并写入种子数据：admin 角色、默认配置）
python start_app.py
```

### 2.3 启动 / 停止

| 方式 | 命令 | 说明 |
|------|------|------|
| 开发/日常 | `python start_app.py` | 一键启动：Flask(8080) + 机台通讯运行时；自动打开浏览器 |
| Windows | 双击 `Start All.bat` | 管理后台 + 采集终端 |
| 后台服务 | `python production.py` | 生产模式（等待 Waitress） |
| HTTPS | `start_https.bat` | 需先配置 `SECRET_KEY` 环境变量 |
| 停止 | Ctrl+C / 杀进程 | 正常退出会自动关闭机台 Socket |

> ⚠️ **注意**：`start_https.bat` 与 `docker-compose.yml` 在生产模式强制要求 `SECRET_KEY` 环境变量，未设置会拒绝启动（安全设计）。

### 2.4 生产部署（Linux）

```bash
# systemd（见 deploy/mes-factory.service）
sudo cp deploy/mes-factory.service /etc/systemd/system/
sudo systemctl enable --now mes-factory

# nginx 反代（见 deploy/nginx.conf）：80/443 → 127.0.0.1:8080
# Docker
docker compose up -d   # 需在 .env 中设置 SECRET_KEY
```

### 2.5 访问地址

| 系统 | 地址 |
|------|------|
| 管理后台 | http://<服务器>:8080/admin |
| 采集终端 | http://<服务器>:8080/ |

## 3. 账号与权限管理

### 3.1 角色体系

| 角色 | role_key | 说明 |
|------|----------|------|
| 超级管理员 | admin | 拥有全部权限，权限校验直通 |
| 普通用户 | user | 默认角色，按分配的权限 key 生效 |

> 内置角色在首次建库时自动写入（`sys_role` 表）。管理员可按需新增角色并配置权限。

### 3.2 用户管理

入口：管理后台 → 系统管理 → 用户管理（`/api/sys/user/*`）。

1. **新增用户**：填写用户名、初始密码、真实姓名、部门、角色；用户状态默认启用。
2. **分配角色**：用户通过 `role_id` 关联角色，权限继承自角色的 `menu_ids`（权限 key 列表）。
3. **停用账号**：状态置 0 后立即生效（登录时校验，已登录会话下次请求失效）。
4. **改密**：用户可自助改密；管理员可直接重置。

> ⚠️ 首次上线**必须修改默认管理员密码**；系统已移除所有"默认口令"提示与预填。

### 3.3 权限模型（管理员必读）

权限校验链：`login_required`（登录）→ `admin_required`（仅 admin）→ `permission_required('模块:动作')`（细粒度）。

- 权限 key 命名：`模块:资源:动作`，例如 `prod:batch:write`（批次维护）、`inv:write`（库存写）、`flow:approve`（审批）、`doc:write`（文档上传）。
- 权限目录：系统管理 → 权限目录（`sys_ext.ACTION_PERMISSION_CATALOG`）列出全部可用权限 key，新增/编辑角色时勾选。
- **admin 角色直通**：拥有 admin 角色的用户不受权限 key 限制（系统管理功能建议仅授予 admin）。

**最小权限原则**：普通员工只授予其岗位必需的权限（如操作工给报工权限、仓管员给库存权限），写权限（增删改/过账/审批）务必谨慎。

## 4. 基础数据维护（首次上线必做）

基础数据是业务运行的前提，**必须先于业务使用完成初始化**：

| 数据 | 入口 | 说明 |
|------|------|------|
| 车间/工序 | 基础数据 → 车间/工序 | 定义车间与工序编码 |
| 产品/BOM | 基础数据 → 产品/BOM | 产品档案 + 物料清单（BOM） |
| 工艺路线 | 基础数据 → 工艺路线 | 工序顺序与标准工时 |
| 供应商/客户 | 基础数据 → 供应商/客户 | 采购与销售往来单位 |
| 计量单位/缺陷分类 | 基础数据 → 字典 | 单位换算、缺陷类型 |
| 库位/仓库 | 库存 → 仓库库位 | 三级库位（仓库-区域-货位） |

> 支持 Excel 导入（`/api/import/<table>`，仅 admin）。导入前请用模板核对列名。

## 5. 系统配置

系统配置存放于 `sys_config` 表（`/api/ai/config*` 等接口维护）：

| 配置项 | 说明 |
|--------|------|
| ai_enabled / ai_provider / ai_api_key / ai_model | AI 扩展（当前为占位，接入需配置 Provider 与 Key） |

其他运行配置通过环境变量控制：`MES_HOST`、`MES_PORT`、`MES_WORKERS`、`MES_ENV`、`SECRET_KEY`、`MES_ADMIN_HOST`（管理后台默认仅绑定 127.0.0.1）。

## 6. 数据备份与恢复

### 6.1 界面备份（推荐）

管理后台 → 备份管理（`/api/backup/*`）：

| 接口 | 功能 |
|------|------|
| `/api/backup/create` | 立即创建备份 |
| `/api/backup/list` | 备份列表 |
| `/api/backup/download/<id>` | 下载备份文件 |
| `/api/backup/restore` | 从备份恢复（**会覆盖当前数据，请谨慎**） |
| `/api/backup/delete` | 删除备份 |

### 6.2 文件备份

SQLite 单文件数据库，直接复制 `database/mes.db` 即可（建议停止写入或使用 SQLite 在线备份 API 时复制）。

**备份策略建议**：
- 每日自动备份（可配合系统 cron / 计划任务），保留 30 份滚动；
- 重要操作（上线前、批量导入前）手动备份一次；
- 备份文件异地存放（另盘/对象存储）。

## 7. 日志与审计

| 日志 | 位置 | 用途 |
|------|------|------|
| 登录日志 | `sys_login_log` 表 | 登录成功/失败记录（IP、时间） |
| 流程状态日志 | `scm_procurement_status_log` 等 | 单据状态流转留痕 |
| 服务运行日志 | `logs/` 目录 | 后端运行与错误 |
| 在线用户 | 系统管理 → 在线用户 | 当前登录用户（`record_online_user`） |

管理员应定期检查登录失败记录，发现异常 IP 及时处置。

## 8. 日常运维与排障

| 现象 | 原因 | 处理 |
|------|------|------|
| 页面能打开但提示未登录 | 会话过期/Cookie 异常 | 重新登录；检查服务器时间是否准确 |
| 登录报"验证码已过期/错误" | 验证码 5 分钟过期、输错 3 次销毁 | 刷新验证码重试；**登录失败 5 次后强制验证码** |
| 报"请求过多 / Too many requests" | 接口限流（默认 50 次/小时/API，仅统计 /api/ 请求） | 等待 `retry_after` 秒后重试；频繁触发需排查异常调用 |
| 启动报 SECRET_KEY 缺失 | 生产模式安全校验 | 设置强随机 `SECRET_KEY`（`openssl rand -hex 32`） |
| 管理后台无法从外部访问 | 默认仅绑定 127.0.0.1 | 设置 `MES_ADMIN_HOST=0.0.0.0`（注意安全） |
| 采集端扫码无反应 | 扫码枪焦点/机台协议 | 检查采集端输入焦点；AIM 机台协议见《AIM机台接入操作手册》 |

## 9. 安全加固清单（上线前逐项核对）

## 10. 扩展功能边界说明

| 功能 | 状态 | 说明 |
|------|------|------|
| AI 质检/智能分析 | 占位（503） | 需配置 Provider/Key 后接入 |
| ERP 同步 | 占位（501） | 需明确对接系统后实现 |
| 采购收料闭环 | 已实现 | 到货登记→收料过账→库存更新→采购单联动 |
| 权限双轨 | 兼容模式 | 菜单权限 + 动作权限并存，别名映射为兼容旧配置 |
