# MES 工厂管家 · 岗位职责与操作流程手册

> 适用对象：各业务岗位员工 · 版本：2026-08 · 配套文档：《使用手册》《系统管理员手册》《模块业务逻辑手册》
>
> 每个岗位章节包含：**岗位目标 → 核心职责 → 系统操作流程 → 上下游衔接 → 注意事项**。

---

## 岗位总览与主业务流程

```
销售订单 → 生产计划(计划员) → 工单下发(计划员) → 任务分配(车间主任)
  → 领料(操作工/仓管员) → 扫码报工(操作工) → 质检(质检员)
  → 入库(仓管员) → 设备保障(设备管理员) / 采购补给(采购员)
```

| 岗位 | 使用入口 | 核心单据 |
|------|----------|----------|
| 系统管理员 | 管理后台（全模块） | 用户/角色/配置/备份 |
| 生产计划员 | 管理后台 → 生产管理 | 计划、工单 |
| 车间主任/班组长 | 管理后台 → 生产/看板 | 任务、审批 |
| 生产操作工 | 采集终端 | 任务、报工、领料 |
| 质检员 | 管理后台 → 质量管理 | 检验单、SPC、处置单 |
| 仓管员 | 管理后台 → 库存管理 | 出入库单、库存 |
| 设备管理员 | 管理后台 → 设备管理 | 台账、维修、保养 |
| 采购员 | 管理后台 → 采购管理 | 采购单、到货收料 |

## 1. 生产计划员

**岗位目标**：把销售订单转化为可执行的生产计划与工单，保证产能与交期。

**核心职责**：
- 依据销售订单制定生产计划与排程
- 创建/下发生产工单（含工艺路线、BOM 冻结）
- 跟踪工单执行进度，处理计划变更

**操作流程**：
1. 登录管理后台 → **生产管理 → 生产计划**：根据销售订单创建计划，选择产品、数量、交期
2. **计划排程**：按产能分配车间/产线，生成批次
3. **工单管理 → 新增工单**：选择产品、数量、计划批次，系统自动冻结工艺路线与 BOM
4. **下发工单**：状态从"草稿(0)" → "已下达(1)"，车间任务开始可见
5. 执行中如需调整：暂停(4)/取消(6)工单需填写原因，已报工数量不可减少

**上下游**：接收销售订单 → 交付车间主任；与采购员衔接物料齐套。

**注意**：工单数量与批次数量强校验，超量会报错；工单一旦有报工记录不可删除，只能暂停或关闭。

## 2. 车间主任 / 班组长

**岗位目标**：组织班组按工单完成生产任务，保证质量与进度。

**核心职责**：
- 接收工单并拆分为班组任务，分配给操作工
- 监控任务进度与看板，协调瓶颈
- 审核报工记录（如有审核环节）、处理异常

**操作流程**：
1. 登录管理后台 → **生产管理 → 任务管理**：查看已下达工单的任务列表
2. **任务分配**：为任务指定操作工/工位
3. 通过**工作台/看板**实时查看：任务状态、报工数量、进度百分比
4. **报工审核**（如启用）：在报工列表中核对数量与工单匹配后审核通过(1)，异常则驳回(3)并注明原因
5. 生产异常时：标记任务暂停，通知设备管理员/质检员协同处理

**上下游**：接收计划员工单 → 输出完工数量给质检/入库。

**注意**：过站校验（AIM 机台）由工艺路线控制，操作工扫码过站不符合顺序会被拦截——班组长需熟悉站点顺序配置。

---

## 3. 生产操作工

**岗位目标**：按任务完成生产/组装/加工，并如实报工。

**核心职责**：
- 扫码领取任务（工单号/任务号）
- 按工艺要求操作，机台过站（如适用）
- 完成任务后扫码报工；领料/退料
- 发现质量问题即时上报

**操作流程**（采集终端，弱网可用，支持离线排队）：
1. 打开采集终端 → 登录（工号+密码；失败 5 次需输验证码）
2. **首页/扫码**：扫描工单条码或任务条码，系统显示任务与工艺要求
3. **任务**：查看待执行任务，点击开始
4. **报工**：输入完工数量 → 提交；离线时自动进入离线队列，联网后自动同步
5. **领料**：按 BOM 领料（如启用），记录批次
6. 结束：退出登录

**上下游**：从车间主任接收任务 → 报工数据给计划员/质检。

**注意**：报工数量必须真实，超工单数量会被拦截；机台过站需按顺序（V2 协议含 HMAC 签名，防伪报工）。

## 4. 质检员

**岗位目标**：把关来料、过程与出货质量，驱动不良闭环处置。

**核心职责**：
- **IQC 来料检验**：采购到货后按检验标准抽检
- **PQC 过程检验**：生产过程巡检、首件检验
- **OQC 出货检验**：成品出货前检验
- **SPC 统计分析**：监控关键工序质量趋势（控制图/CPK）
- **不良处置**：对不合格品创建处置单（返工/报废/让步接收），跟踪闭环

**操作流程**：
1. 登录管理后台 → **质量管理**
2. **IQC**：待检列表 → 新增检验单（选来料批次、检验项目、判定合格/不合格）
3. **PQC/OQC**：新增检验 → 记录检测项数据 → 判定
4. **不良处置**：不合格品 → 新建处置单 → 选择动作（返工 rework / 报废 scrap / 让步 concession）→ 提交审批 → 按结论执行 → 关闭
5. **SPC**：查看控制图与 CPK，超出控制限时触发预警并跟进纠正

**上下游**：IQC 衔接仓管员到货；PQC/OQC 衔接操作工报工；处置单闭环到生产与计划。

**注意**：处置单有状态机（待审 → 已批 → 任务已建 → 已完成），未关闭前对应 SN/批次不可流转。

## 5. 仓管员

**岗位目标**：保证物料/成品出入库及时、账实相符。

**核心职责**：
- 入库：采购到货入库、生产完工入库、退货入库
- 出库：生产领料出库、销售发货出库
- 库存查询：余额、批次追溯、预警
- 盘点与库存调整

**操作流程**：
1. 登录管理后台 → **库存管理**
2. **入库**：新增入库单（选类型：采购/生产/其他）→ 填明细（物料、数量、库位）→ **过账**（状态 0草稿→1过账），库存余额即时更新
3. **出库**：新增出库单 → 填明细 → 过账扣减库存
4. **批次追溯**：按批次号查询该批次的所有入库/出库/消耗记录（与质量处置联动）
5. **库存预警**：查看低于安全库存的物料清单，通知采购员

**上下游**：IQC 合格后入库；领料服务生产；与采购员衔接到货收料。

**注意**：单据过账后不可直接编辑删除（需冲销）；过账强校验库存是否充足，不足会被拦截。

## 6. 设备管理员

**岗位目标**：保障设备完好率，降低故障停机。

**核心职责**：
- 设备台账维护（档案、参数、状态）
- 维修工单：报修受理 → 派工 → 维修 → 验收
- 保养计划：按周期生成保养任务并执行登记
- 机台接入管理（AIM 协议、读码器、边缘网关设备）

**操作流程**：
1. 登录管理后台 → **设备管理 → 设备台账**：新增/编辑设备（编码、车间、状态）
2. **维修工单**：受理报修 → 派工给维修工 → 填写维修记录与耗材 → 完工验收
3. **保养计划**：定义保养周期 → 到期生成保养任务 → 执行后登记保养记录
4. **设备联网**（如适用）：在设备接入模块查看机台在线状态、AIM 过站记录

**上下游**：与车间主任协同处理设备故障导致的停机；机台接入文档见《AIM机台接入操作手册》。

---

## 7. 采购员

**岗位目标**：按需采购，保障物料供给，跟踪到货与收料。

**核心职责**：
- 创建采购订单（选供应商、物料、数量、交期）
- 提交审批并跟踪采购单状态
- **到货登记与收料**：供应商到货后登记，收料过账入库
- 供应商管理

**操作流程**：
1. 登录管理后台 → **采购管理**
2. **采购单**：新增 → 选供应商/物料/数量/交期 → 保存（草稿0）→ 提交（进入审批流）→ 审批通过后生效
3. **到货登记**：货物到达 → 登记到货通知（关联采购单）
4. **收料过账**：选择到货明细 → 指定仓库/库位/批次 → 收料过账 → 系统自动更新库存余额并推进采购单状态（含质检需求的自动生成 IQC 待检）
5. 跟踪采购单状态日志，处理延期/异常

**上下游**：衔接计划员物料需求与仓管员入库；IQC 检验在收料后触发。

**注意**：收料过账为事务操作，重复过账有幂等保护；无采购单的到货需先补单。

## 8. 系统管理员（职责速览）

完整内容见《系统管理员手册》，此处仅列岗位要点：

| 任务 | 频率 | 入口 |
|------|------|------|
| 用户开户/角色分配 | 人员变动时 | 系统管理 → 用户/角色 |
| 基础数据维护 | 上线/变更时 | 基础数据模块 |
| 数据备份 | 每日 | 备份管理 / 文件复制 |
| 日志审计 | 定期 | 登录日志、状态日志 |
| 系统排障 | 按需 | 见管理员手册第 8 章 |

| 质检员 | quality_inspector | quality:write、qm:process:list |

> 实际权限以系统管理 → 权限目录中的定义为准，遵循最小权限原则分配。
