# MES 订单驱动端到端验收案例

版本：2026-08-10

本案例用于人工验证本次补全后的生产业务链。所有记录备注统一填写 `生产业务链测试`，验收后保留，不清理。

## 一、验收基础数据

| 模块 | 示例值 |
| --- | --- |
| 客户 | 验收客户 A / `CUS-ACCEPT-A` |
| 车间 | 装配验收车间 / `WS-ACCEPT-A` |
| 成品 | 智能控制盒 A / `FG-ACCEPT-A` / 单位“台” |
| 原料 | 控制板 / `RM-PCB-A`；外壳 / `RM-CASE-A` |
| BOM | 每台：控制板 1、外壳 1 |
| 工序 | 装配、功能测试、包装，全部属于装配验收车间 |
| 工艺路线 | 控制盒 A 装配路线，V1；装配 → 功能测试（检验点）→ 包装 |
| 销售数量 | 10 台，单价 500 |
| 计划数量 | 10 台 |
| 生产批次 | 6 台 + 4 台（本次手工只跑 6 台批次） |
| 原料初始库存 | 控制板 20、外壳 20 |

## 二、手工执行流程

1. 在“基础数据 → 车间设置”创建车间。
2. 在“基础数据 → 工序管理”创建三道工序，所属车间必填。
3. 在“产品定义”和“物料清单”创建成品、原料与 BOM。
4. 在“工艺路线”创建路线，选择产品、默认车间、版本，添加三道有序步骤。
5. 在“生产管理 → 销售订单”新增订单，选择客户，添加产品 10 台、单价 500。
6. 在“生产计划”选择该销售订单，系统带入剩余 10 台，选择装配验收车间后保存。
7. 在“生产批次”把计划明细先拆 6 台、再拆 4 台；尝试再拆 1 台应被拒绝。
8. 在“工单管理”选择 6 台批次，确认产品和车间自动带入，选择 V1 路线后保存。
9. 点击“下达并冻结”，再点击“生成任务”和“生成领料需求”。
10. 在“生产领料”对控制板和外壳分别申请 6、发料 6、收料 6；库存各减少 6。
11. 在“报工管理”选择装配任务，提交合格 6；提交后任务数量仍为 0。
12. 对报工执行“审核”，数量仍为 0；再执行“记账”，任务和工单合格数增加 6。
13. 在“工序转移”从装配转到功能测试 6 台。尝试从装配直接转到包装应被拒绝。
14. 功能测试任务提交合格 5、不良 1，审核并记账；转移合格 5 到包装。
15. 包装任务尝试报工 6 应被拒绝；报工 5、审核、记账应成功。
16. 返回生产领料，对外壳退料 1；外壳库存恢复 1，并出现“生产退料”库存事务。

## 三、必须核对的结果

| 检查项 | 预期结果 |
| --- | --- |
| 页面切换 | 销售订单、计划、路线、任务、报工各显示自己的页面，不残留上一模块 |
| 工序车间 | 新增/编辑不选车间不能保存 |
| 路线过滤 | 工单只能选择同产品、同车间的启用路线 |
| 快照 | 下达后修改基础路线或 BOM，工单冻结内容不变 |
| 计划拆批 | 6 + 4 成功，再加 1 被拒绝 |
| 任务生成 | 与冻结路线步骤一致，重复点击不重复生成 |
| 领料库存 | 发料原子扣库存；库存不足不产生部分扣减；退料恢复库存 |
| 报工状态 | 提交/审核不累计，记账只累计一次 |
| 工序转移 | 只允许相邻步骤，不能超过来源已记账合格数量 |
| 后续报工 | 不能超过实际转入数量 |
| 排列 ID | 表格升降或移动位置时，显示排列 ID 随记录交换，真实主键不改变 |
