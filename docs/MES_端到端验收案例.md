## 二、请你手动执行的案例 B

### 测试目标

验证真实人员使用时的完整链路：

```text
PC 建工单 → PC 建任务 → 采集端接收任务 → 开始任务
→ 扫码 → 分两次报工 → 完工 → 来料质检 → 看板核对
```

### 测试数据

请使用以下数据，备注中必须填写唯一标记：

| 项目 | 值 |
| --- | --- |
| 测试标记 | `MANUAL-20260808-01`，如果重复请改成当天日期和序号 |
| 产品 | `P001 / p` |
| 车间 | `镭雕车间` |
| 工序 | `镭雕` |
| 计划数量 | `12` |
| 优先级 | `5` |
| 任务分配人 | 当前登录的 `admin` |
| 第一次报工 | 合格 `8`，不良 `1` |
| 第二次报工 | 合格 `4`，不良 `0` |
| 质检供应商 | `手动验收供应商-MANUAL-20260808-01` |

### 第 1 步：PC 创建工单

1. 打开 [PC 管理后台](http://127.0.0.1:8080/admin)。
2. 进入“生产管理 → 工单管理”。
3. 点击“新增”。
4. 填写：产品 `P001 / p`、车间 `镭雕车间`、计划数量 `12`、优先级 `5`、状态“待开始”。
5. 备注填写 `MANUAL-20260808-01`。
6. 保存后记下系统自动生成的工单号，例如 `WO20260808000020`。

预期结果：工单列表能看到 12 的计划数量，完成数量为 0，状态为待开始。

### 第 2 步：PC 创建任务

1. 进入“生产管理 → 任务管理”。
2. 点击“新增”。
3. 选择刚才的工单。
4. 选择工序“镭雕”。
5. 选择分配人员 `admin`。
6. 计划数量填写 `12`，备注填写同一个测试标记。
7. 保存后记下系统自动生成的任务号，例如 `TK20260808000030`。

预期结果：任务状态为待开始，任务出现在 admin 的“我的任务”中。

### 第 3 步：采集端接收任务

1. 打开 [采集客户端](http://127.0.0.1:8080/)。
2. 使用 `admin / admin123` 登录；如果你已修改密码，请使用新密码。
3. 点击“任务”。
4. 确认能看到刚创建的任务。
5. 点击“开始任务”。

预期结果：任务状态变为进行中，任务卡片可以进入“生产报工”。

### 第 4 步：扫码进入工单

1. 点击底部“扫码”，不要点击首页快捷卡片也可以。
2. 直接手动输入刚才记下的工单号，按回车。
3. 确认出现工单信息和镭雕任务。
4. 点击进入报工。

如果摄像头权限不可用，使用手动输入即可；这不影响业务流程。

预期结果：扫码只负责识别和带入业务对象，不会在没有点击确认前产生报工。

### 第 5 步：第一次报工

填写：

- 合格数量：`8`
- 不良数量：`1`
- 备注：`MANUAL-20260808-01-第一次`

点击“确认报工”。

预期结果：

- 报工提示成功；
- 任务完成数变为 8，不良数变为 1；
- 任务仍为进行中；
- 工单完成数变为 8，不良数变为 1；
- 首页“今日报工”增加 1；
- 看板今日合格产出增加 8、今日不良数量增加 1。

### 第 6 步：第二次报工完成工单

再次进入同一任务，填写：

- 合格数量：`4`
- 不良数量：`0`
- 备注：`MANUAL-20260808-01-第二次`

提交后预期结果：

- 任务完成数为 12；
- 任务状态变为已完成；
- 工单完成数为 12；
- 工单状态变为已完成；
- 今日合格产出总计增加 12；
- 今日不良数量总计增加 1。

### 第 7 步：提交来料质检

1. 点击底部“质检”。
2. 供应商填写 `手动验收供应商-MANUAL-20260808-01`。
3. 检验结果选择“合格”。
4. 备注填写 `MANUAL-20260808-01-来料检验`。
5. 点击“提交检验”。

预期结果：出现“检验已提交”，待检列表数量减少 1。

### 第 8 步：核对生产看板

打开 [生产看板](http://127.0.0.1:8080/kanban)，点击“立即刷新”，检查：

- 工单是否从进行中列表消失或显示已完成逻辑；
- 今日合格产出是否增加 12；
- 今日不良数量是否增加 1；
- 活跃工单数量是否变化；
- 质量待处理数量是否因质检提交而减少；
- 页面是否显示“数据在线”。
