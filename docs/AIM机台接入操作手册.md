# AIM机台接入操作手册

## 上线准备

MES服务器必须使用固定内网IP，例如`192.168.10.20`。不要把PPT示例中的`127.0.1.5`配置给另一台电脑。机台工控电脑需要与MES网络互通，防火墙只向车间OT网开放所需TCP端口。MES中必须提前准备设备台账、产品、冻结工艺路线、已下达工单、任务和产品SN。

## 配置通讯端点

进入“设备管理 → 机台通讯 → 通讯端点 → 新增端点”，配置设备、工序、工站、穴位、监听IP、端口、协议和编码。

- 旧机台选择V1，新机台选择V2。
- 正式V2机台建议配置共享密钥，机台使用相同密钥计算HMAC-SHA256签名。
- V1正式生产必须填写机台来源IP白名单，只有该IP可以建立连接。
- 一个监听IP和端口只能对应一个端点。
- 双穴旧机台使用不同端口，例如穴位1使用2004、穴位2使用2005。
- 修改启用端点后重启生产服务，使Socket监听配置生效。

## 启动服务

执行`python production.py`。生产入口会升级数据库，为每个启用端点启动独立Socket子进程，再启动MES Web服务；Web服务退出时会回收Socket进程。

## 通讯协议

### 海康读码器直连 MES

长盈现场的海康 IDMVS 读码器配置为 **TCP 服务端** 时，MES 选择“通讯方向：MES直连海康读码器”，填写读码器 IP 和 `2002` 端口。MES 会主动连接读码器，读码器发送条码内容后由 MES 直接执行准入判定，并回写 `<L1>`（允许）或 `<L3>`（拒绝）。PPT 当前关闭了回车和换行输出，因此直连客户端按短暂 TCP 空闲切分一帧；`无结束符切帧空闲(ms)` 默认 80，可按现场发送间隔调整。

读码器输出建议只保留条码内容；若数据处理格式带有分号附加字段，MES 取第一个字段作为 SN。读码失败的 `NoRead` 会记录为 `NO_READ` 并回写 `<L3>`。直连模式下返回字符串不附加 CR/LF，匹配 PPT 中固定的 `<L1>/<L2>/<L3>` 管脚事件控制。

直连链路：

```text
海康读码器 TCP Server:2002  <-- MES TCP Client
              条码 / NoRead
                    --> MES 判定
              <L1> / <L3>
```

原“MES监听机台”方向继续保留，适用于机台工控机作为 TCP Client 的旧现场。

V1请求与响应：

```text
SN001\r\n
<L1>\r\n
<L3>\r\n
```

V2未配置密钥：

```text
REQ|2|AIM001|LASER01|CAVITY1|R0001|SN001\r\n
```

配置密钥时，末尾增加前7字段的HMAC-SHA256十六进制签名：

```text
REQ|2|AIM001|LASER01|CAVITY1|R0001|SN001|SIGNATURE\r\n
```

允许与拒绝响应：

```text
ACK|2|R0001|L1|OK|镭雕模板|检测模板|允许加工\r\n
ACK|2|R0001|L3|WRONG_STEP|||当前应执行工序：清洗\r\n
```

请求号在同一端点内唯一，重复请求返回第一次的相同判定。

## 模拟器联调

V1：

```powershell
python machine_simulator.py --host 127.0.0.1 --port 2004 --protocol 1 --sn SN001
```

V2：

```powershell
python machine_simulator.py --host 127.0.0.1 --port 2004 --protocol 2 --device AIM001 --station LASER01 --cavity CAVITY1 --request-no TEST001 --sn SN001
```

V2配置密钥后追加`--secret your-secret`。模拟数据和请求号应备注为测试。

## CSV检测报告

前四列必须为`2D Barcode,Date,Time,OK(1)/NG(0)`，后续列是不同机台的动态检测点。日期支持`YYYY/M/D`或`YYYY-MM-DD`，时间使用`HH:MM:SS`，结果支持`OK/NG`或`1/0`。

进入“设备管理 → 机台通讯 → 检测报告”，填写端点ID并上传CSV。测试样例位于`examples/aim/ok.csv`和`examples/aim/ng.csv`；使用前必须将第一列改成已经取得L1的真实测试SN。

### 文件目录自动采集

在“设备管理 → 机台通讯 → 通讯端点 → 编辑”中配置：

- CSV输入目录：机台工控电脑本机目录或Windows已挂载的绝对目录，例如 `D:\AIM\Result`。
- 文件稳定秒数：默认2秒。文件大小和修改时间连续稳定后才导入，避免读取尚未写完的CSV。

MES只扫描输入目录顶层的`.csv`文件。成功文件归档到`machine_archive\年\月\日`；失败文件移入输入目录的`_failed`文件夹，并在“检测报告”显示失败原因。修正SN、工单、任务或模板后，管理员点击失败行“重试”，系统使用服务器保存的原隔离文件重新导入。

同一CSV按内容哈希去重，改名或重复复制不会重复报工。单文件最大5MB，每轮每端点最多处理20个文件。运行MES服务的Windows账号必须拥有输入目录的读取、写入、移动和删除权限；健康栏显示“目录缺失”时检查共享映射、服务账号和网络。

## 业务结果

- L1只允许本次加工，不增加产量。
- OK报告创建SN PASS过站及待审核合格报工。
- NG报告创建待审核不良报工，不创建PASS过站。
- 报工审核和过账后才更新任务、工单数量。
- 相同请求或相同CSV不会重复记账。

## NG质量处置与返工流程

1. AIM导入NG报告后，系统自动生成SN级质量处置单，并把SN置为“质量冻结”。普通任务仍以合格数量判断是否完成，不良数量只保留为质量损失历史。
2. 品质人员进入“现场管理 → 返工报废”，查看处置单、SN、原检测报告、工单、工序和返工周期，选择“返工”“报废”或“让步接收”。
3. 选择返工时，系统只创建计划数为1的草稿返工任务，不会自动开工。草稿状态扫码返回`REWORK_TASK_NOT_STARTED`。
4. 生产主管点击“启动返工”，返工任务进入进行中。此时目标SN在原工序扫码可取得L1，其他SN不能占用该返工任务。
5. 返工复检OK后，审核并过账报工：返工任务完成，原任务和工单补记1件合格品，SN恢复正常；原不良数量不会被清除。
6. 返工复检仍为NG时，当前返工周期结束，系统自动生成下一周期待审核处置单，SN重新进入质量冻结。
7. 选择报废后SN永久禁止生产；选择让步接收后生成带处置单关联的PASS记录，但保留原NG和不良报工。

生产异常恢复时不要直接修改数据库数量。应从处置页继续审核/启动，或从“机台通讯 → 检测报告”重试失败CSV，以保持处置单、任务、报工和SN追溯一致。

本机软件测试保留了工单`TEST-AIM-FILE-WO`、SN `SIM-AIM-20260816-002`及返工任务`RW-QD-BACKFILL-4`。验证结果为：原任务合格2/2、不良历史1，返工任务合格1/1，处置单完成，SN恢复正常。

## 常见L3原因

| 原因码 | 含义 | 处理 |
|---|---|---|
| `NO_READ` | 扫码失败 | 放入扫码异常区 |
| `UNKNOWN_SN` | SN不存在 | 检查SN及工单绑定 |
| `ENDPOINT_DISABLED` | 端点停用 | 启用端点，等待服务自动同步 |
| `EQUIPMENT_UNAVAILABLE` | 设备停用或维修 | 检查设备台账 |
| `WORKORDER_UNAVAILABLE` | 工单不允许生产 | 检查工单状态 |
| `WRONG_STEP` | 工序不匹配 | 完成上工序或修正绑定 |
| `TASK_NOT_FOUND` | 没有当前任务 | 从工单生成任务 |
| `QUALITY_HOLD` | SN处于质量冻结 | 由品质人员审核处置单 |
| `REWORK_TASK_NOT_STARTED` | 已批准返工但任务未启动 | 由生产主管启动返工任务 |
| `SN_SCRAPPED` | SN已报废 | 禁止再次投入生产 |
| `ROUTE_COMPLETED` | SN已完成路线 | 检查重复投入 |
| `PROTOCOL_ERROR` | 报文、身份或签名错误 | 检查字段、编码和密钥 |

## 单机试点验收

1. 正确SN返回L1。
2. 错工序、未知SN、NoRead返回L3。
3. 断网时机台停止加工，恢复后能够重连。
4. OK报告只生成一条待审核合格报工和PASS过站。
5. NG报告只生成一条待审核不良报工。
6. 重复请求和重复CSV不重复记账。
7. 后台可以查看在线会话、准入日志、耗时和检测报告。
8. 双穴设备使用不同端口时互不串号。
9. NG后扫码返回`QUALITY_HOLD`，批准返工但未启动时返回`REWORK_TASK_NOT_STARTED`。
10. 返工OK后原任务只增加合格数，不减少历史不良数，且重复过账不重复累计。
