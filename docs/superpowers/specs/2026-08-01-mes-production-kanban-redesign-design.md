# MES 生产看板完整改造设计

日期：2026-08-01  
状态：待用户最终审阅

## 1. 目标与边界

本阶段在采集终端完成后改造 `/kanban`，把当前写在 Python 字符串中的四宫格页面升级为适合车间电视与会议大屏持续展示的深色生产指挥屏。看板聚焦核心生产指标、工单进度、车间产出、设备状态、质量预警、刷新状态与全屏运行。

继续复用 Flask、原生 JavaScript 和 ECharts，不引入前端框架。现有 `/api/kanban/realtime` 保持兼容，可在同一响应中增加明确字段。看板页面本身可以公开打开，但实时业务数据仍受登录会话保护；未登录或会话过期时展示登录提示，不循环报错。

## 2. 文件与架构

将 `backend/blueprints/kanban.py` 中的内嵌 `KANBAN_HTML` 拆出为独立静态页面、样式和脚本。蓝图只负责数据接口和发送页面；看板脚本负责数据获取、视图映射、图表生命周期、刷新控制与全屏交互。

看板不复用采集端业务状态或离线写队列，只共享稳定的语义颜色、数字格式化和安全文本渲染原则。页面不能依赖 CDN 才能显示核心数据；ECharts 继续使用项目现有本地资源或加入可随应用打包的本地副本。

## 3. 视觉与布局

采用深色“车间指挥屏”方向：

- 页面底色以 `#071426`、`#0B1F3A` 为主，面板使用轻微层次与细边框，不使用廉价霓虹描边。
- 主数据使用高对比白色与蓝色，正常、警告、危险分别使用绿、琥珀和红，红色只用于真实异常。
- 顶栏显示 MES 生产看板、当前日期时间、在线/过期状态、最后更新时间、刷新与全屏按钮。
- 第一层展示今日合格数、不良数、合格率、进行中工单数和设备运行率。
- 主区域展示进行中工单进度表、车间产出排行、质量概览和设备状态分布。
- 1920×1080 为主要目标，1366×768 保持全部核心内容可见；超窄屏不作为主要展示模式，但不得产生脚本错误。

数字变化可使用一次 180–300ms 淡入或数值过渡；图表更新不得整页闪烁。遵循 `prefers-reduced-motion`。

## 4. 数据与交互

`/api/kanban/realtime` 返回一个带服务器时间的完整快照，至少包含：

- 进行中/待开始工单与计划完成进度；
- 今日合格数、不良数和可推导合格率；
- 各车间今日产出；
- 设备按运行、维修、停用统计；
- 当前可从既有数据可靠计算的质量预警摘要。

前端每 30 秒请求一次数据，浏览器标签恢复可见时立即刷新。删除现有 `<meta http-equiv="refresh">` 整页刷新和没有实际页面切换的伪轮播，ECharts 实例只初始化一次，后续使用 `setOption` 更新，并在窗口变化时统一 `resize`。

全屏按钮和 F11 快捷键使用同一状态函数；浏览器拒绝全屏时给出非阻断提示。手动刷新不得产生并发重复请求。

## 5. 失败与过期状态

首次加载失败时显示可重试错误态；已有成功快照后刷新失败时保留最近数据，并在顶栏显示“数据可能已过期”和最后成功时间。连续失败不会清空图表，也不会以 0 覆盖真实的最近值。

401 响应显示“登录后查看生产数据”及管理后台登录入口。非 JSON、超时和 5xx 使用统一错误信息；恢复成功后自动清除过期提示。

空工单、空车间、零设备和零产出都有明确空状态。合格率在分母为零时显示 `--`，避免把无生产错误表达为 0% 合格率。

## 6. 安全与部署

- 表格内容通过 DOM `textContent` 构建，不把工单号、产品名或车间名拼接进 HTML。
- 页面、CSS、JS 和图表依赖必须纳入 PyInstaller 数据文件，离线内网部署不依赖公共 CDN。
- 数据接口保留登录保护；前端不嵌入账号、密码或长期令牌。
- 页面自动刷新只执行 GET，不产生任何业务写操作。

## 7. 测试策略

Node 测试先覆盖快照映射、合格率零分母、过期状态、工单安全渲染、图表单次初始化和并发刷新抑制。Python 测试覆盖实时接口字段、服务器时间、零数据、设备统计与登录保护。测试必须先因目标行为缺失而失败，再实现代码。

浏览器验收在 1920×1080 与 1366×768 下覆盖首次加载、手动刷新、30 秒刷新、模拟接口失败后的陈旧数据提示、恢复成功、全屏切换和窗口缩放。检查控制台无重复 ECharts 初始化、未处理 Promise 或外部 CDN 加载失败。

## 8. 验收标准

- 看板呈现统一、清晰、适合远距离阅读的深色生产指挥屏。
- 核心指标、工单、车间、设备和质量数据均来自真实接口，不包含伪轮播或装饰性假数据。
- 30 秒局部刷新不重载页面，不重复创建图表实例；手动刷新与自动刷新不会并发。
- 失败时保留最近快照并标记过期，恢复后自动回到在线状态。
- 1920×1080 和 1366×768 下无重要内容遮挡、溢出或不可操作区域。
- 页面资源可随桌面包离线运行，自动化与浏览器验收全部通过。

## 9. 非目标

- 不开发拖拽式看板设计器、跨工厂轮播或自定义指标平台。
- 不修改生产、质量或设备业务单据。
- 不把看板改成可编辑管理页面。
- 不在本阶段继续修改采集终端或管理后台。
