MES工厂管家 · 使用手册

面向中小制造企业的轻量级制造执行系统（MES），覆盖「销售订单 → 生产计划 → 工单 → 报工 → 质量检验 → 入库追溯」全流程数字化。本文档帮助用户快速安装、上手并熟练使用系统的每一处功能。

版本：v1.0.0 适用对象：管理员 / 计划员 / 班组长 / 一线操作员 文档类型：终端用户手册

1. 系统概述

MES工厂管家是一套零依赖部署、双端协同的制造执行系统。它把生产现场的计划、执行、质量、仓储与设备连接起来，让每一次操作都有实时数据支撑。

核心优势

  • 零依赖 默认 SQLite，无需额外数据库服务
  • 双端协同 PC 管理后台 + 移动采集终端
  • 开箱即用 一键启动，5 分钟完成部署
  • 模块化 40+ 功能模块，按需启用

技术架构

后端Flask 2.x（RESTful API）
数据层SQLite / 可切 MySQL / PostgreSQL
前端原生 HTML/CSS/JS
可视化ECharts
报表openpyxl（Excel 导入导出）
架构分层：用户层（采集终端 8080 / 管理后台 8081）→ 服务层（Flask API：auth / system / production / quality / …）→ 数据层（SQLite：sys_* base_* prod_* inv_* eqp_* …）。

2. 安装与启动

2.1 环境要求

依赖版本说明
Python3.8+推荐 3.10+
pip20.0+包管理
Flask2.xWeb 框架
openpyxl3.xExcel 处理

2.2 Windows 一键启动

双击项目根目录下的 Start All.bat，会自动拉起采集终端（8080）与管理后台（8081）。

2.3 手动启动（推荐用于调试）

# 安装依赖
pip install flask openpyxl

# 终端 1：采集终端（移动端）
cd frontend && python run.py        # → http://localhost:8080

# 终端 2：管理后台（PC 端）
cd admin && python run.py           # → http://localhost:8081/admin

2.4 Docker 部署

docker build -t mes-factory .
docker run -p 8080:8080 -p 8081:8081 mes-factory

3. 快速上手

3.1 首次登录

  1. 浏览器打开 http://localhost:8081/admin（管理后台）或 http://localhost:8080（采集终端）。
  2. 输入用户名 admin / 密码 admin123。
  3. 点击「登录系统」进入工作台。
  4. 进入后尽快修改默认密码（见 3.2）。

3.2 修改密码

管理后台右上角用户头像 → 修改密码，或调用接口：

POST /api/sys/user/change-password
{ "old_password":"admin123", "new_password":"你的新密码" }

3.3 界面布局

管理后台（PC）

  • 左侧栏：主导航菜单（按模块分组）
  • 顶栏：全局搜索、通知铃铛、主题切换（深/浅色）、退出
  • 内容区：列表 / 表单 / 图表；多数列表支持分页、关键字搜索、批量操作

采集终端（移动）

  • 底栏导航：首页 / 扫码 / 任务 / 报工 / 质检 / 库存

  • 离线模式：弱网时数据暂存本机，恢复后一键同步

4. 管理后台功能详解

管理后台是系统的「指挥中枢」，按模块组织。以下按模块说明常用操作。

4.1 工作台 / 仪表盘

登录后默认进入仪表盘，集中展示生产进度、良率、设备状态、待办等关键指标。图表数据来自 /api/dashboard 与 /api/dashboard/charts，支持大屏看板（/api/kanban/production、/api/kanban/realtime）。

4.2 系统管理

系统监控/api/sys/monitorCPU / 内存 / 磁盘占用

数据备份/api/backup/*手动创建 / 恢复 / 下载备份

4.4 生产管理

销售订单→ 生产计划→ 工单→ 任务→ 报工
  • 销售订单：录入客户订单（/api/prod/sales/list）。
  • 生产计划：将订单拆解为生产计划（/api/prod/plan/list）。
  • 工单：下发工单，系统自动生成工单号（/api/prod/workorder/add）。
  • 任务：工单拆分为可执行任务，分配给班组/人员（/api/prod/task/list）。
  • 报工：一线在采集终端或后台提交报工（/api/prod/report/add，含合格数/不良数）。

4.5 质量管理

检验类型说明接口

PQC 过程检验产线过程抽检/api/qm/process/list
OQC 出货检验成品出货前检验/api/qm/outgoing/list

不良品分析不良原因归集/api/qm/*

4.6 库存 / 设备 / 工具

库存管理

  • 入库单 / 出库单（/api/inv/inbound/*）
  • 库存余额查询（/api/inv/balance/list）
  • 物料批次追溯
  • 库存预警（低于阈值提醒）

设备管理

  • 设备台账（/api/eqp/ledger/*）
  • 维修工单（/api/eqp/repair/*）
  • 保养计划与记录（/api/eqp/maintenance/*）
  • 保养逾期提醒（/api/eqp/maintenance/overdue）
  • 点检（/api/eqp/check/*）

工具管理

  • 工具类型 / 台账（/api/tool/type/* /api/tool/ledger/*）
  • 借用与归还（/api/tool/borrow/*）

4.7 排班 / 流程 / 报表

  • 排班管理：班组（/api/sched/team/*）与排班计划（/api/sched/plan/*）。
  • 流程（审批）管理：流程定义（/api/flow/definition/*）、流程实例、待办（/api/flow/pending/count）。
  • 报表统计：生产报表（/api/report/production），支持导出 PDF / Excel（/api/report/production/pdf）。

4.8 分析 / 追溯 / 通知

  • 数据分析：良率（/api/analytics/yield）、OEE（/api/analytics/oee）、交期预警（/api/analytics/delivery-alert）、库存周转（/api/analytics/inventory-turnover）、数据看板（/api/analytics/data-dashboard）。
  • 追溯：批次列表（/api/trace/batch/list）、按关键字查询（/api/trace/query?keyword=）、按 SN 查询过站记录。
  • 全局搜索：/api/search/global?q= 一键检索产品 / 工单 / 设备。
  • 消息通知：通知列表（/api/notification/list）、未读计数（/api/notification/unread/count）。

5. 采集终端使用

采集终端面向一线操作员，通过底部导航快速完成扫码、报工、质检等动作。建议用手机/平板浏览器或 PDA 访问 http://localhost:8080。

底部导航功能操作要点
首页当日任务概览、待办提醒一眼掌握本班进度
扫码扫描工单号 / 任务号条码对接扫码枪或相机
任务查看分配给我的任务按状态筛选
报工提交合格数 / 不良数对应 /api/prod/report/add
质检IQC/PQC/OQC 快捷检验一键录入检验结果
库存物料查询 / 出入库操作现场核对库存
离线友好：当网络中断，终端顶部显示「离线」并暂存报工数据至本机；恢复网络后点击「立即同步」即可补传（offline_queue.js 实现）。

5.1 制程管控（过站防呆）

对于需要工序流转的产品，可在采集终端或后台执行制程操作（接口前缀 /api/process/*）：

操作接口说明
过站/api/process/pass-station含防呆校验，防止跳工序
跳站/api/process/skip-station需填写跳站原因
出站/api/process/exit-station完成当前站点
重工/api/process/rework退回目标站点返工
关箱 / 拆箱/api/process/close-box /api/process/open-boxSN 装箱管理
锁料 / 解料/api/process/lock-material冻结异常物料
返线/api/process/return-to-line不良品退回产线

防呆规则在「站点配置」（/api/process/station-config/list）中维护；制程统计见 /api/process/statistics。

6. 核心业务流程

一个标准生产闭环如下：

① 销售订单→ ② 生产计划→ ③ 工单下发→ ④ 任务分配→ ⑤ 一线报工→ ⑥ 质量检验→ ⑦ 入库追溯
  1. 录入销售订单：管理后台「生产管理 → 销售订单」新增客户订单。
  2. 制定生产计划：将订单转为计划，指定产品、数量、交期。
  3. 下发工单：系统自动生成工单号，关联工艺路线。
  4. 拆分任务：把工单拆成任务并指派班组/个人。
  5. 一线报工：操作员在采集终端扫码 → 报工（合格/不良数量）。
  6. 质量检验：IQC/PQC/OQC 按节点录入，SPC 实时监控工序能力。
  7. 入库与追溯：成品入库，批次/序列号全程可追溯。

7. 高级功能

  • SPC 控制图：采集质量数据后自动绘制 Xbar-R / 单值图，计算 CPK，识别异常点。
  • 数据看板 / 大屏：/api/kanban/* 提供实时产量、良率、设备 OEE 大屏展示。
  • 审批流：在「流程管理」自定义审批定义，工单/采购等可走审批。
  • 高级排程（APS）：aps 模块支持更智能的排产（扩展能力）。
  • 多租户：tenant 模块支持多工厂/多组织数据隔离。
  • 集成扩展：erp_deep（ERP 对接）、iot（设备联网）、ai（智能分析）为可选扩展模块。

8. 运维与数据

8.1 数据库切换

默认使用 SQLite（database/mes.db）。切换到 MySQL / PostgreSQL 时，设置环境变量即可，无需改代码：

SET MES_DB_TYPE=mysql
SET MES_DB_HOST=127.0.0.1
SET MES_DB_PORT=3306
SET MES_DB_NAME=mes
SET MES_DB_USER=mes_user
SET MES_DB_PASS=******
库表按模块加前缀（sys_ 系统 / base_ 基础 / prod_ 生产 / inv_ 库存 / eqp_ 设备 / qm_ 质量 …），初始化时自动建表并建索引。

8.2 备份与恢复

在「系统管理 → 备份」点击创建备份（POST /api/backup/create），异常时下载并恢复。建议定期备份 database/mes.db。

8.3 日志与监控

操作日志（/api/sys/log/*）记录关键动作；系统监控（/api/sys/monitor）实时显示服务器资源。

9. 常见问题 FAQ

Q1：登录提示密码错误？

确认默认账号 admin / admin123；若已改密，请用新密码。忘记密码可重置 database/mes.db 中用户表或恢复备份。

Q2：访问 8081 打不开？

确认已运行 admin/run.py；检查防火墙是否放行端口；或查看控制台报错。

Q3：采集终端离线了怎么办？

终端会自动暂存报工数据，顶部显示「离线」。恢复网络后点「立即同步」即可补传，数据不会丢失。

Q4：如何导出报表？

管理后台「报表统计 → 生产报表」支持导出 PDF / Excel（/api/report/production/pdf）。

Q5：想换数据库（如 MySQL）？

设置第 8.1 节的环境变量后重启服务即可，无需改动代码。
